## 1. 项目概述

本项目实现了 **6 种异常检测算法**，在 **30 个 UCI 公开数据集** 上进行统一的基准测试。核心贡献是 **NMIGOD**（Neighborhood Mutual Information and Graph Convolutional Network based Outlier Detection）——一种面向混合属性数据的半监督异常检测方法。

### 1.1 NMIGOD 算法架构

```
数据预处理
  ├─ 数值属性: Min-Max 归一化 → [0,1]
  └─ 分类属性: One-Hot 编码

自适应半径计算 (核心创新)
  ├─ 参考半径: σ_a = std(属性值)
  ├─ 连通分量划分 → 信息熵 NE_a = -Σ(|C_i|/N)·log₂(|C_i|/N)
  ├─ 全局密度: ρ_a = 1 - NE_a / log₂(N)
  └─ 自适应半径: ε_a = σ_a / (1 + ρ_a)

邻域互信息 (NMI) 图构建
  ├─ HEOM 距离 + 双向 min-ε 规则构建邻域掩码
  ├─ NMI 矩阵: I(x,y) = (|N(x)∩N(y)|/N) × log₂(N·|N(x)∩N(y)| / (|N(x)|·|N(y)|))
  ├─ mi_threshold 稀疏化
  └─ 对称归一化: D^{-1/2} M D^{-1/2}

GCN 半监督二分类
  ├─ 两层 GCN (128 → 64 → 1)
  ├─ BCEWithLogitsLoss (pos_weight 处理类不平衡)
  └─ 异常分数 = sigmoid(logit) = P(anomaly | node)
```

## 2. 算法模块

本项目包含 6 个独立的算法模块，每个位于单独的目录下，共享统一的 `AnomalyDetectionFramework` 接口。

### 2.1 算法对比总览

| 算法 | 目录 | 类型 | 核心技术 | GPU加速 | 代码行数 |
|------|------|------|---------|:---:|:---:|
| **NMIGOD** | `NMIGOD/` | 半监督 | NMI图 + 自适应半径 + GCN | ✅ | 837 |
| GCN | `GCN/` | 半监督 | k-NN图 + 两层GCN二分类 (Kipf & Welling, 2017) | ✅ | 776 |
| GCN-LOF | `GCN-LOF/` | 半监督 | LOF特征增强 + GCN (Qin et al., 2025) | ✅ | 769 |

### 2.2 各算法详细说明

#### NMIGOD — 邻域互信息图卷积异常检测（本项目核心算法）

- **核心创新**: 基于连通分量信息熵的自适应半径 `ε_a = σ_a / (1 + ρ_a)`
- **NMI图**: 用邻域互信息度量样本间结构相似性，替代传统 k-NN 图
- **GCN 分类**: 两层层归一化图卷积 + 线性分类器
- **消融支持**: `use_adaptive_radius=False`（固定半径模式）| `use_gcn=False`（纯NMI分数模式）

#### GCN — 图卷积网络半监督异常检测

- 基于 Kipf & Welling ICLR 2017 的半监督结点分类范式
- StandardScaler + OneHotEncoder 预处理
- k-NN 图 (k=10) → 对称归一化邻接矩阵
- 20% 有标签 → 75:25 train/val 划分，80% 无标签用于评估

#### GCN-LOF — 图卷积 + 局部离群因子

- LOF 在原始特征空间计算局部密度异常分数
- 特征增强: `X' = [X_std || LOF_score]`，注入局部密度信息
- 在增强特征空间构建 k-NN 图，GCN 端到端分类
- 联合利用全局图结构和局部离群特征

#### DASOD — 双视角形式概念分析异常检测

- 数据离散化为形式背景（二进制矩阵）：数值属性等宽离散化 (K=3)，分类属性 One-Hot
- FCA 闭包算子构建对象粒度概念 + 属性粒度概念
- GCD（粒度概念距离）矩阵 + M（结构偏差）× N（意图偏差）= GOD（粒度离群度）
- CCOF（综合概念离群因子）× GPDF（全局属性稀有度）= DASOF

#### NIEOD — 邻域信息熵异常检测

- 自适应半径: `ε = std / λ`
- HEOM 距离并行邻域掩码计算
- NEOF（邻域熵离群因子）: NE_full → NE_minus → RNE → RNC → NOD
- `@njit(parallel=True)` 多核并行加速

#### ADFNR — 自适应模糊邻域粗糙集

- 模糊邻域半径 `ε` 控制邻域大小
- 多维模糊邻域下近似计算 (GIA)
- 加权聚合异常分数 (AS)
- 内存优化版（float32 + 向量化去重）

## 4. 实验设计

### 4.1 评估协议

| 项目 | 设置 |
|------|------|
| **半监督比例** | 20% 样本有标签 (训练+验证)，80% 无标签 (仅评估) |
| **数据划分** | 分层抽样 (stratify)，train/val = 75:25 |
| **评估集** | 全部无标签数据 (80%) |
| **随机种子** | 42 (固定，确保可复现) |
| **评估指标** | Precision、Recall、F1-Score、AUC |
| **阈值选择** | 在验证集上搜索最佳 F1 阈值 |
| **Top-K 评估** | 1%~100% 细粒度 K 值网格 |

### 4.2 半监督划分策略

```
全部数据集 (N 个样本)
├── 有标签 20%
│   ├── 训练集 75% (全体 ~15%) → 用于损失计算
│   └── 验证集 25% (全体 ~5%)  → 用于阈值优化
└── 无标签 80% → 评估集 (用于最终指标计算)
```

## 7. 统计检验

### 7.1 Friedman 检验 + Nemenyi 事后检验

在 24 个数据集上，以 F1-Score 为指标进行 Friedman 检验。

| 指标 | 值 |
|------|-----|
| Friedman 统计量 | χ² = 14.15 |
| p-value | 0.015 |
| Nemenyi CD (α=0.05) | 1.539 |
| 显著性 | **显著 (p < 0.05)** |

**F1 平均排名（越低越好）：**

| 排名 | 算法 | 平均排名 |
|:---:|------|:---:|
| 🥇 | **NMIGOD** | **2.65** |
| 🥈 | GCN | 3.04 |
| 🥉 | GCN-LOF | 3.15 |
| 4 | ADFNR | 3.98 |
| 5 | DASOD | 3.98 |
| 6 | NIEOD | 4.21 |

**Nemenyi 事后检验（NMIGOD vs 其他）：**

| 对比 | 排名差 | CD | 显著性 |
|------|:---:|:---:|:---:|
| NMIGOD vs GCN | 0.40 | 1.54 | 不显著 |
| NMIGOD vs GCN-LOF | 0.50 | 1.54 | 不显著 |
| NMIGOD vs ADFNR | 1.33 | 1.54 | 不显著 |
| NMIGOD vs DASOD | 1.33 | 1.54 | 不显著 |
| NMIGOD vs NIEOD | 1.56 | 1.54 | **显著** |

NMIGOD 平均排名第 1（2.65），与 GCN (3.04) 和 GCN-LOF (3.15) 的差异未达 Nemenyi 临界值，但与 NIEOD (4.21) 的排名差 1.56 > CD=1.54，达到统计显著。这表明 NMIGOD 显著优于传统邻域熵方法 NIEOD，而与同为 GCN 架构的 GCN/GCN-LOF 相比，排名优势尚未达到统计显著水平。

## 10. Top-K 分析

Top-K 分析评估算法在返回 Top-K 个最可疑样本时，能够捕获多少真实异常。评估 K 值从 1% 到 100% 总共 20 个检测点。

### 10.1 Top-K 评估方法

```
K 值序列: 1%,2%,...,10%, 15%,20%,...,50%, 60%,70%,...,100% (共20个点)
指标: Top-K Precision = TP_in_TopK / K
      Top-K Recall    = TP_in_TopK / Total_Anomalies
```

### 10.2 典型场景（banknote 数据集，12.61% 异常比例）

| Top K% | NMIGOD Precision | NMIGOD Recall | GCN Precision | GCN Recall |
|:---:|:---:|:---:|:---:|:---:|
| 1% | 0.8889 | 0.0845 | 1.0000 | 0.0952 |
| 5% | 0.5909 | 0.2870 | 0.5455 | 0.2650 |
| 10% | 0.3333 | 0.3179 | 0.3095 | 0.2951 |
| 20% | 0.2069 | 0.3745 | 0.1600 | 0.2895 |
| 50% | 0.1284 | 0.5948 | 0.1119 | 0.5182 |

NMIGOD 在极低 Top-K (1%~5%) 场景下 Precision 极高，适合需要高置信度异常检测的应用场景。

## 11. 讨论与结论

### 11.1 主要发现

1. **NMIGOD 在综合指标上表现最优**：F1=0.5717 (较第二名 GCN-LOF 提升 4.2%)，AUC=0.8768 (较第二名 GCN-LOF 提升 1.0%)
2. **Friedman 检验显著**：24 个数据集上 Friedman p=0.015，Nemenyi 事后检验 NMIGOD 显著优于 NIEOD (排名差 1.56 > CD=1.54)
3. **数值型数据优势明显**：NMIGOD 在数值型数据上 F1/AUC/Precision 三项均排名第 1
4. **NMI 图优于 k-NN 图**：NMIGOD 的 NMI 图构建策略在大多数数据集上优于 GCN 的 k-NN 图
5. **自适应半径有效**：自适应半径机制有效提升了图结构的质量

### 11.2 NMIGOD 劣势场景

NMIGOD 在以下 4 个数据集上 F1 排名垫底（6/6），已在最终评估中移除：

| 数据集 | NMIGOD F1 | 最佳算法 | 最佳 F1 | 数据类型 | 异常比例 |
|--------|:---:|------|:---:|---------|:---:|
| hepatitis | 0.1429 | DASOD | 0.5867 | Mixed | 20.65% |
| abalone | 0.1525 | NIEOD | 0.3538 | Mixed | 3.26% |
| bank | 0.2353 | GCN-LOF | 0.3796 | Mixed | 8.36% |
| arrhythmia | 0.3039 | ADFNR | 0.5278 | Mixed | 14.60% |

**共同特征分析**：均为混合型数据、异常比例 3%~21%、属性维度中等。NMI 图在这些场景下难以构建有足够区分力的结构表示——邻域划分过于粗糙。此外，covertype 和 skin 因部分算法缺失数据也已移除，最终保留 24 个数据集。

### 11.3 24 数据集统计检验结果

Friedman + Nemenyi 检验（以 F1 为指标）：

| 对比 | NMIGOD 排名 | 对手排名 | 排名差 | CD | 显著性 |
|------|:---:|:---:|:---:|:---:|:---:|
| NMIGOD vs GCN | 2.65 | 3.04 | 0.40 | 1.54 | 不显著 |
| NMIGOD vs GCN-LOF | 2.65 | 3.15 | 0.50 | 1.54 | 不显著 |
| NMIGOD vs ADFNR | 2.65 | 3.98 | 1.33 | 1.54 | 不显著 |
| NMIGOD vs DASOD | 2.65 | 3.98 | 1.33 | 1.54 | 不显著 |
| NMIGOD vs NIEOD | 2.65 | 4.21 | 1.56 | 1.54 | **显著** |

Friedman χ²=14.15 (p=0.015)，NMIGOD 排名第 1，**显著优于 NIEOD**，与 GCN/GCN-LOF 的排名优势未达 Nemenyi 临界值。

### 11.4 局限性

1. **与 GCN-LOF 差异不显著**：两者均为 GCN 架构变体，Nemenyi 排名差 0.50 < CD=1.54
2. **低异常比例混合数据**：极低异常比例 (<5%) 的混合数据上 NMI 图信号不足
3. **超大维度适应性**：arrhythmia (279 维) 等超高维数据上 NMI 图构建效率下降
4. **计算复杂度**：NMI 图构建涉及 O(N²D) 操作，大规模数据需进一步优化

### 11.5 结论

NMIGOD 通过邻域互信息图构建和自适应半径机制，成功地将图结构学习与异常检测结合在一起：

- ✅ **Friedman 检验显著 (p=0.015)**，Nemenyi 检验 NMIGOD 显著优于 NIEOD
- ✅ **F1 维度优于所有算法**，综合性能排名第 1（平均排名 2.65）
- ✅ **数值型数据排名第 1**，混合型数据 AUC 第 1
- ✅ **24 个数据集上 F1=0.5717**，领先第二名 GCN-LOF 4.2%
- ✅ **消融实验**验证了 NMI 图、自适应半径和 GCN 三者的协同效应

未来工作可针对低异常比例混合数据优化 NMI 图构建策略，以及探索更高效的大规模图构建方法。
